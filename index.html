Link2QR · 链接转二维码

点一下图标，当前网页链接立刻变成二维码——像草料一样好用的 Chrome 扩展。下载 PNG、复制图片、右键任意链接生成，颜色与导出尺寸可调。

GitHub 仓库 安装方法 在线试玩

能做什么

打开即出码点击扩展图标，自动读取当前标签页 URL 生成二维码
右键菜单对链接、页面、选中文字一键「生成二维码」，新标签页打开
下载 / 复制导出 256–2048px PNG（模块整数对齐不糊）、复制图片到剪贴板
颜色与尺寸前景色、底色自由调，偏好本地记忆，下次打开还在
中文与 EmojiUTF-8 字节模式编码，任意文本、长文本都能扫
零权限追踪仅 activeTab / contextMenus / storage / clipboardWrite，不碰网页内容

安装方法

  1. 打开 Chrome，地址栏输入 chrome://extensions
  2. 右上角打开「开发者模式」
  3. 点「加载已解压的扩展程序」，选择克隆下来的仓库目录
  4. 工具栏点 Link2QR 图标，或右键任意链接试试

在线试玩

输入任意文字或链接，实时生成——用的就是扩展内置的同一套二维码引擎（qrcode-generator, MIT）。
